# FORGE+ Gym and Fitness Center Template

FORGE+ is a responsive, multi-page gym and fitness center website template built with HTML, CSS, Bootstrap, and a small JavaScript enhancement for the contact form.

## Pages

- `index.html` — Home
- `about.html` — About the club
- `training.html` — Training options
- `membership.html` — Membership details
- `contact.html` — Contact details and email form
- `blog.html` — Journal listing
- `blog-post.html` — Journal article

The home page includes a full-width, auto-advancing hero slideshow with three image-and-copy slides, manual controls, and left-aligned training links. The theme uses a red accent, configurable through the CSS custom properties at the top of `css/style.css`. The shared stylesheet is in `css/style.css`, the contact form script is in `js/contact.js`, and the local image assets are in `images/`. Bootstrap and Google Fonts are loaded from their respective CDNs.

## Contact form

The contact form validates the required fields in the browser and opens the visitor's default email application with a prefilled message addressed to `hello@forgeclub.co`. It does not submit data to a server. Update that address in `contact.html` and `js/contact.js` to match your business, or connect a server-side form endpoint before deploying if you need direct online submissions.
